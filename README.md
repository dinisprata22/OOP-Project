# OOP-Project
## Project Overview
- This project is a Java-based graphical implementation of the classic puzzle game Sokoban, developed as an academic project for an Object-Oriented Programming (POO) course at ISCTE
- The game replaces the traditional warehouse worker with a Forklift (Empilhadora) and introduces several custom gameplay mechanics beyond the standard crate-pushing puzzle.
